# Storage and the corpus

Invariant: **`raw/` is never mutated; `derived/` is always recomputable from it.**
Layout comes from `StorageSettings`: `raw_dir`, `derived_dir`, `events_dir`, `session_log(s)`.

## `adapters/storage/schemas.py` — the on-disk bar format

`SCHEMA_VERSION = "1"`. `BAR_SCHEMA` is a `pyarrow` schema.

- Prices are `decimal128(18, 8)`, quantities `decimal128(28, 8)` — **not float**. The `Decimal`
  invariant survives the round-trip to disk.
- `Source` (`StrEnum`) records where each row came from; mixed-source sessions are detectable.
- `bar_to_row` / `row_to_bar` are the only conversion path, tested as a round-trip.
- `PARTITION_KEYS = ("venue", "ticker", "session_date")`, with an **explicit**
  `SESSION_PARTITIONING` — see `08-gotchas` for why inference is not safe here.

## `parquet_store.py` — the corpus writer

Hive-partitioned Parquet under `raw/`. `write_bars(bars, source, session_date)`,
`read_bars(...)`, `sessions(symbol)`.
Dedupe key is `("interval", "ts_event", "seq")`, so re-running a backfill over ground already
covered is idempotent rather than duplicating rows.

## `duckdb_catalog.py` — asking the corpus what it holds

DuckDB queries the Parquet files in place; nothing is copied into a database.

- `Coverage` — bars held for a session; `is_complete(expected)`, `is_mixed_source()`.
- `Gap` / `gaps()` — intra-session holes, with `missing_bars()`.
- `sessions_held()` / `missing_sessions()` — needs an expected-session list, i.e. a **trading
  calendar, which does not exist yet.** This is the seam the corpus quality gate plugs into.
- `duplicate_timestamps()` — the correctness check that the dedupe key is doing its job.
- `summary()` — corpus-wide counts.

## `core/codec.py` — exact event serialisation

**Lives in `core`, not in `adapters/storage`** (moved there deliberately: the event log's
format is a domain concern, and `EventStorePort` sits in `core/ports.py`).

`CODEC_VERSION = "1"`. `EventCodec.register(...)` maps each event type to an encoder/decoder
pair; `_TYPE_KEY = "_t"` tags the row. `encode`/`decode`, `dumps`/`loads`.

- **Decimals are encoded as strings.** JSON numbers are IEEE doubles; a round-trip through one
  would silently destroy the precision the whole `Decimal` invariant exists to protect.
- Keys are sorted, so the byte output is stable — which is what lets the replay digest mean
  anything.
- An unregistered type raises `UnknownEventType` rather than being silently dropped.

## `event_store.py` — the append-only log

JSONL, one event per line, via `EventCodec`. `append`, `flush`, `close`, `stream(start, end)`.
`CorruptEventLog` on a malformed line — a truncated log fails loudly instead of replaying a
prefix and looking fine.

Implements `EventStorePort`. Holds a lazily-opened `IO[str] | None`; has a `__del__` with
`contextlib.suppress` because `filterwarnings = ["error"]` turns a leaked handle into a test
failure — which is the correct behaviour, and needed handling rather than silencing.

A committed fixture lives at `tests/fixtures/session.jsonl` (357 events), generated by
`scripts/make_replay_fixture.py`. `make replay` defaults to it, so the target works on a fresh
clone even though nothing writes session logs until the live engine lands.
